# plan

Write a plan for a code change before any code is written.

```
/am-plr:plan <what to build or change>
```

**What it does**

- Makes sure plan mode is on; stops if you don't switch.
- Asks about anything unclear first.
- Reads the code, then writes a 5-part plan: Overview, Issues and solutions, Files, Achievements, Action steps.
- Follows `rules/code.md` and `rules/python.md`.

Next: `/am-plr:plan-review` to check the plan.

Instructions for Claude: [SKILL.md](SKILL.md).
