# prompt-writer

Turn a rough idea into a clear, ready-to-paste prompt.

```
/am-plr:prompt-writer <rough description>
```

**What it does**

- Asks up to 3 questions, only if a gap really matters.
- Applies prompt best practices: task first, context, clear output format, success criteria.
- Returns the prompt in a code block, what it changed, and any assumptions.

It writes the prompt; it doesn't do the task.
